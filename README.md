# CIDM-SIM Parallel Futures

**Nebius x NVIDIA Global AI Hackathon — Physical AI**

CIDM-SIM Parallel Futures evolves a latent physical information state with **CIDM/CIDM-BER** and branches multiple plausible futures using a learned **Stochastic Information Reservoir (SIR)**.

This repository is the public hackathon implementation. Full project files and documentation will follow in subsequent commits.
