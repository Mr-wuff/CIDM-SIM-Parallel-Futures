# Public competition IP boundary

The competition requires a public repository with an OSI-approved license.

Recommended to publish:
- competition source code in this repository;
- the public reference CIDM implementation needed to reproduce the demo;
- SIR, branching, Nebius adapter and demo code;
- synthetic generators and public benchmark summaries.

Do not automatically publish:
- private datasets;
- partner data;
- credentials;
- research-only checkpoints;
- unrelated internal experiment archives;
- patent-sensitive material not yet cleared for publication.
